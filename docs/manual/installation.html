Instalace HW Inventory na Microsoft IIS

Tento dokument popisuje doporučený postup pro nasazení minimální varianty HW Inventory na Microsoft IIS s využitím SQL Serveru.

1. Předpoklady

  • Windows Server 2019 nebo novější se zapnutou rolí Web Server (IIS).
  • Nainstalované .NET 8 Hosting Bundle (obsahuje .NET Runtime i ASP.NET Core Module v2).
  • SQL Server 2019+ (lokální instance nebo dostupná přes síť).
  • Účet s oprávněním vytvářet databáze a zapisovat do cílového adresáře webu.
Poznámka: Pokud používáte minimální režim, externí konektory (LDAP, SMTP, SMS) nejsou pro instalaci povinné. Lze je nakonfigurovat později v administraci.

2. Příprava artefaktů

  1. Na build stroji spusťte PowerShell skript scripts/builder.ps1 s parametrem -Mode Publish, případně využijte GitHub Actions, které generují adresář publish/.
  2. Zkontrolujte, že ve výsledném balíku jsou podsložky publish/api, publish/web, logs a updates.
  3. Připravte si konfigurační soubor appsettings.Production.json s hodnotami připojení na SQL Server (viz kapitola „První spuštění“).

3. Vytvoření IIS zdrojů

  1. Spusťte PowerShell skript scripts/installer.ps1 z balíku na cílovém serveru.
  2. Zadejte cílovou cestu (např. C:\inetpub\HWInventory) a připojení na SQL Server.
  3. Skript vytvoří aplikaci v IIS, konfiguruje App Pool (No Managed Code) a připraví adresářovou strukturu včetně šifrování výchozího hesla správce (DPAPI).

4. První spuštění aplikace

  1. Otevřete prohlížeč a přejděte na URL webu (např. https://inventory.internal.local).
  2. Proběhne průvodce prvním spuštěním, ve kterém můžete zvolit Lokální režim – dokončíte tím nastavení bez externích konektorů.
  3. Po dokončení se přihlaste výchozím účtem admin@localhost / heslo uvedené ve výstupu instalátoru (doporučená okamžitá změna).

5. Smoke test

Pro ověření funkčnosti spusťte PowerShell skript scripts/smoke-test.ps1 s parametry URL webu a přístupových údajů. Skript ověří:

  • Úspěšné přihlášení.
  • Vytvoření serveru, síťového zařízení a pracovní stanice přes API.
  • Záznam operací v auditním logu.

6. Další kroky

  • Proveďte konfiguraci číselníků v sekci Nastavení → Číselníky.
  • V případě potřeby nakonfigurujte SMTP/LDAP/SSO/SMS konektory a aktivujte dvoufaktorovou autentizaci.
  • Pro integraci s tiskárnami a storage vyplňte příslušné konektory v nastavení.
