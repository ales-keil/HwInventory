Evidence serverů, síťových prvků a pracovních stanic

Administrace nabízí tři specializované sekce – Servers, Network a Workstations. Všechny respektují přiřazené datové scopy (oddělení, lokace) a auditují každou změnu.

1. Základní operace

  • Vytvoření – tlačítko Nový otevře formulář s povinnými poli (název, inventární číslo, stav).
  • Úpravy – editace probíhá inline, změny se ukládají tlačítkem Uložit.
  • Vyřazení / Obnovení – hromadné akce dostupné z toolbaru (možnost vybrat více položek).
  • Smazání – vyžaduje heslo aktuálně přihlášeného uživatele.

2. Specifická pole

Entita Povinná pole Rozšířená pole
Servery Název, Inventární číslo, Prostředí, OS, Role/typ, Status WSUS priorita, Správce, Zástupce, Rack pozice, VLAN1–3 + IP1–3, Podpora do
Síťové prvky Název, Inventární číslo, Typ zařízení, Status Umístění, Rack pozice, VLAN1–3 + IP1–3, SupportUntil, Správce/Zástupce
Pracovní stanice Název, Inventární číslo, OS, Typ stanice, Status Uživatel, Department, CPU/RAM/Storage, MAC, VLAN1–3 + IP1–3, Handover workflow

3. Filtry a export

  • Každá tabulka podporuje rychlé filtry (status, prostředí, typ) a fulltext přes název/inventární číslo.
  • Rozšířené filtry v API přijímají JSON strukturu { field, op, value } s whitelistem podporovaných polí.
  • Exporty lze plánovat z modulu Import/Export v několika formátech (CSV/XLSX).

4. Předávací protokoly (Workstations)

  • Tlačítko Předat vytvoří schvalovací požadavek – e-mail s tlačítky „Přijmout“ / „Odmítnout“.
  • Po potvrzení novým vlastníkem systém aktualizuje pole Owner, Department a Location a uloží auditní diff.
  • Super Admin může vynutit převod bez souhlasu – odesílá se informační e-mail s PDF protokolem.
Tip: Pro správnou vazbu VLAN/IP je nutné mít v číselnících definované všechny VLANy včetně typu (DMZ/LAN). UI zobrazí pouze aktivní položky číselníků.
